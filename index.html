O que é HTML?

É uma linguagem de marcação usada para estruturar páginas da internet.

O que é JavaScript?

É uma linguagem de programação que adiciona interatividade às páginas web.

Para que serve o CSS?

Serve para definir cores, fontes, tamanhos e o visual de uma página web.
